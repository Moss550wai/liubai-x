留白 REPLY SIEVE

少读一点噪声。
多留一点注意力。

打开一条 X 帖子，留白会在本机筛选下面的文字回复。父帖作者的普通补充默认保留；如果他接话的上级已折叠，这条接话也收起。正常回复保持原样，折叠回复统一归到底部，一个入口展开全部。

01 / 把选择留在手边

展开 / 收起
当前已加载内容底部只留一个“已收起 N 条回复”入口。点一次展开全部，再点一次收起；展开后是连续文字列表，不必逐条点开。新评论加载后入口跟随后移，换帖或刷新清空本次归集。
不该折叠
本次页面恢复这条回复的原位置，并在本机记下纠错；刷新后重新判断。不会改变模型，也不会自动将账号加入白名单。
总是保留
展开底部列表，点击对应回复的“保留账号”，或者从面板输入 @用户名。白名单账号恢复 X 原样；在面板中可以移除白名单。
查看原回复
底部展示当时读取的文字。图片、视频和点赞等操作，请点击“查看原回复”在新标签页查看。X 回收原节点后，已归集文字仍可读，滚回来不会重复计数。
账号屏蔽
请在 X 自带菜单中手动操作。留白没有屏蔽入口，不会自动点击 X 菜单，也没有本地黑名单。

02 / 选择自己的强度

保守、标准、激进使用同一个字符分类器，滑块向右会折叠更多。默认激进的阈值是 0.30，允许误伤；它仍会漏掉一些 AI 味回复。分数不是“AI 作者概率”。

只处理帖子详情页中的回复，不处理首页、搜索结果或原帖。父帖指当前打开的帖子，其作者的普通补充、串文默认保留，回复已折叠内容时显示“随上级收起”。统一展开只展示底部列表；纠错上级或把账号加入白名单时，接话联动恢复。白名单优先。作者暂时读不到时先保留，读到后再处理。正常回复没有标记、工具条或额外空白。只有文字、作者和回复链接都可读取时才处理；图片里的文字不识别，长文展开前只能读到页面当前显示的部分。

父子关系只提取自 X 页面本来就加载的响应，不额外发请求，不按相邻位置猜。关系不全或上级没有读过时，作者接话保留。其他账号仍独立按模型判断。

03 / 数据只留在这里

设置、白名单和纠错记录保存在当前浏览器配置的扩展本地存储（chrome.storage.local），没有云端同步、服务器或自动训练。反馈包含回复原文、账号、链接、时间、用户的“保留”判断，以及当时模型分数、阈值和折叠原因。随上级收起的记录另含父回复 ID；旧记录保留，不把联动折叠当成模型判错。

面板 →「导出反馈」下载 JSON，同时包含设置与白名单。先导出再卸载：移除扩展会丢失本地记录。没有反馈时也可导出空记录。不会读取或导出登录凭证。

暂停开关会恢复原文。正常回复本来就不显示工具条；更新扩展后请刷新 X。X 更新结构后可能影响解析，识别失败的内容保持显示。它是个人阅读筛选工具，不负责鉴定内容是否由 AI 生成。
