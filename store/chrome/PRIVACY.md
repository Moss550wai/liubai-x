# 留白 · X 回复筛隐私政策（Google Chrome 版）

生效日期：2026-11-20。适用产品：Google Chrome 扩展「留白 · X 回复筛」。开发与支持：[Moss550wai/liubai-x](https://github.com/Moss550wai/liubai-x)。

## 目的与范围

本扩展在你打开的 X / Twitter 帖子详情页中，本地筛选文字回复，将命中项收起并集中到底部，供你一次展开。它提供折叠强度、白名单、本地纠错与导出。所有分类使用随扩展打包的字符模型在本机 CPU 完成。

## 访问和临时处理的信息

- 当前详情页已加载回复的文字、作者用户名、回复 ID 和帖子链接，用于评分、展示、白名单和纠错。
- 当前详情页原帖的 ID 和作者用户名，用于保留原帖与作者普通串文。
- X 页面已经请求的 TweetDetail 响应中的帖子 ID、父回复 ID，用于确认作者接话是否跟随上级折叠。读取过程中不检查登录凭证或请求头，不主动发起 X 接口请求；页面脚本向扩展内容脚本只传这对 ID，不传完整响应。
- 图片和视频不做识别；扩展不主动展开长文，不请求账号历史，不使用浏览器 history 或 cookies API。

上述内容可能来自你有权查看的公开或非公开帖子。临时归集仅在页面内存中保存，换帖、刷新或关闭页面后清空，不上传给开发者。

## 本地持久保存的信息

扩展使用浏览器配置中的 `chrome.storage.local`，不使用云同步存储：

1. 开关、折叠阈值。
2. 你主动添加的白名单用户名。
3. 你点击「不该折叠」时保存的回复文字、作者用户名、回复链接、用户「保留」判断、记录时间、随机记录 ID、模型分数、当时阈值、折叠原因和可用的父回复 ID。

不会自动保存一份完整浏览历史或全部阅读内容。持久数据保留在当前浏览器配置，直至你卸载扩展或清除该扩展的本地存储。当前版本没有逐条删除反馈或导入功能。

## 传输、共享与使用限制

扩展不向开发者、广告商、模型服务商或其他服务器发送上述处理结果或纠错数据，没有遥测、广告跟踪或自动训练。数据只用于已说明的回复筛选、界面、白名单和纠错功能；不出售、不用于广告画像、信用或借贷判断。

你主动点击「导出反馈」时，浏览器会在你选择的位置保存一个 JSON 文件，包含设置、白名单和纠错记录；保存后的文件由你自行管理。扩展不会自动把文件发到 GitHub。你主动点击「查看原回复」或外部帮助链接，会打开相应网站，由该网站按其规则处理访问。

本扩展的数据使用遵守 Chrome Web Store User Data Policy 的 Limited Use 限制：仅为上述用户可见功能处理必要信息，不作不相关用途。商店和浏览器自身的安装、更新、付款或账号服务由相应平台另行提供。

## 你的控制

- 在扩展面板暂停后，页面原文恢复；白名单可添加或移除。
- 可在面板导出自己的反馈。卸载前请自行备份；导出文件不会自动删除。
- 不想继续使用时，可在 Google Chrome 扩展管理页禁用或移除本扩展。移除扩展会删除其本地存储；你已自行导出的文件需自行删除。
- 扩展不自动屏蔽、关注、发帖或改变 X 账号关系。需要屏蔽账号时，由你使用 X 原生菜单操作。

## 联系与政策更新

问题和隐私咨询可通过 [GitHub Issues](https://github.com/Moss550wai/liubai-x/issues) 联系维护者。请勿在公开 issue 附上私密回复、完整反馈、登录凭证或个人证件；先去除不希望公开的信息。

若数据处理方式变化，会在更新本政策和发行说明后发布对应版本。
